# e-Arsip Bawaslu Kota Langsa — Prototipe awal

## Isi
- Login demo Admin dan Pegawai
- Ringkasan jumlah surat
- Tambah surat masuk dan surat keluar
- Daftar dan pencarian arsip
- Penyimpanan lokal SQLite (offline)
- Admin dapat menghapus arsip

## Akun demo
- Admin: `admin` / `admin123`
- Pegawai: `pegawai` / `pegawai123`

## Menjalankan
Proyek ini memakai Expo SDK 54. Buka folder proyek di lingkungan Expo yang mendukung SDK 54, lalu jalankan `npm install` dan `npx expo start`.

## Penting
Ini prototipe awal, belum layak dipakai untuk arsip resmi. Login masih demo lokal tanpa keamanan server, belum ada lampiran dokumen, backup/pemulihan, audit log, pengaturan hak akses rinci, atau pengujian keamanan. Jangan masukkan dokumen rahasia/berisi data pribadi sebelum fitur keamanan dan backup ditambahkan.
